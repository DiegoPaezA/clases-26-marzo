¿Cómo prende Arduino algo que necesita más corriente de la que puede dar?

Un pin de Arduino da muy poca corriente. Si queremos encender un ventilador o un motor, necesitamos un ayudante: el transistor, que funciona como un interruptor que se controla con una señal. En estas dos sesiones vas a armarlo, probarlo y, al final, construir una alarma de calor que se activa sola.

Antes de empezar

Para entender: el transistor es como una llave de agua

Un chorrito pequeño en la base abre la llave grande entre colector y emisor. Sin chorrito, la llave queda cerrada.

CORTE

VCE: 4,99 V

Valores de una simulación del mismo circuito. Compáralos con tu registro.

CORTE = interruptor abiertoSin señal en la base no pasa corriente. El LED está apagado y casi todo el voltaje queda entre C y E (≈ 5 V).
SATURACIÓN = interruptor cerradoCon señal en la base la llave se abre del todo. El LED enciende y entre C y E casi no queda voltaje (≈ 0 V).

B. Desconecta el emisor (E) del negativo(el agua no tiene por dónde salir)
C. Voltea el transistor: intercambia C y E(la llave instalada al revés)
¿Y si el LED queda "a medias"?

Si la base recibe muy poca corriente (como con 1 MΩ), la llave se abre solo un poco y el LED queda débil. Esa zona intermedia se usa para amplificar señales (por ejemplo, en un parlante), pero para usar el transistor como interruptor la evitamos: queremos solo dos estados, corte o saturación.
